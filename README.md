# Rahul R - Professional Portfolio

A modern, professional single-page scrolling portfolio website showcasing my skills as a Full-Stack Developer and AI enthusiast.

## 🚀 Features

- **Single-Page Scrolling**: All sections displayed in one seamless scrolling experience
- **Modern Design**: Clean, professional dark theme with emerald/teal color scheme and glassmorphism effects
- **Responsive**: Fully responsive design that works on all devices
- **Smooth Scrolling**: Smooth navigation between sections with anchor links
- **Interactive Elements**: Smooth animations, hover effects, and transitions
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Fast Loading**: Optimized CSS and minimal dependencies

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Styling**: Custom CSS with modern design principles
- **Icons**: Font Awesome
- **Fonts**: Inter (Google Fonts)

## 🏃‍♂️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/rahulr123123/portfolio.git
   cd rahul-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

## 📱 Sections

The portfolio features a single-page scrolling layout with the following sections:

- **Home**: Hero section with introduction and call-to-action buttons
- **About**: Detailed information about background and experience
- **Projects**: Showcase of featured projects with links to GitHub and live demos
- **Skills**: Comprehensive list of technical skills organized by categories
- **Contact**: Contact form and information for professional inquiries
